Terms on this page

Amanuensis
The tool that produced this site. An AI agent runs it to survey a repository.
Survey
The agent's reading of the repository, done in passes, with each conclusion tied to the code it read.
Session
One stretch of work by the agent. Sessions lists them.
Publication check
After building the site, Amanuensis reads it back to confirm it matches the record. About this survey shows the result.
