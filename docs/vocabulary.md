# Glossary

## Scoped to **[B-01](subsystems/b01-survey-methodology-and-agent-contracts.md)**

- **discharge or decline** — The shape every generative obligation in this method takes: satisfy it with one real record, or state out loud that none applies — never a numeric floor.
- **refusal parity** — The rule that a skill reference instructing a call the server refuses must quote the refusal in the words the server returns, so the two sides can be compared mechanically rather than read side by side.

## Scoped to **[B-02](subsystems/b02-mcp-core-persistence-and-lifecycle.md)**

- **independent storage mode** — The .storage-mode marker that makes a project-local .amanuensis/ its own nested git repository and forbids it from ever falling through to the surveyed repository's git.
- **store generation** — The random 32-hex identity a store mints once, at the open that creates store_identity, and never recomputes — the name a carried record calls the conspectus it came out of.

## Scoped to **[B-03](subsystems/b03-knowledge-tools-and-workflow-api.md)**

- **verification object** — What a composition item was verified *over* — either one unit subject at its own target commit, or the whole assembled HEAD in a clean worktree — recorded on the item so a unit pass can never be read as an integral one.
- **wire budget** — The 8192-byte ceiling a list tool's response must fit, measured on the doubled envelope — the indented text block plus the structuredContent that repeats it — not on the payload.

## Scoped to **[B-04](subsystems/b04-diff-aware-materializer.md)**

- **page plan** — The list of pages the current store requires, computed once per render and used four times over: to decide what to write, what to link, what to navigate, and what the read-back must find.

## Scoped to **[B-05](subsystems/b05-packaging-installer-validation-and-product-docs.md)**

- **generated copy, asserted schema** — This repository's rule for a fact published in more than one place: generate every copy that can be generated, and assert the one that cannot rather than rewriting it.
