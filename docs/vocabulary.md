# Glossary

## Scoped to **[B-06](subsystems/b06-report-interface-design-and-validation-studies.md)**

- **production custody** — The provenance chain that connects a design study's captured reading object to an actual generated report revision.
- **reader-task fixture** — A frozen user goal and success criterion used to assess whether a report projection supports a concrete reading task.

## Scoped to **[B-07](subsystems/b07-embedded-research-surveys-and-platform-trials.md)**

- **static-report transfer boundary** — The point where bounded research findings become design or implementation constraints for the generated report.
- **trial snapshot** — A revision-pinned record of trial inputs and observed outputs used to make a platform comparison reproducible.
