# Codex review of the code-index plan, draft 2

`codex exec -s read-only -m gpt-6.1-sol`, 2026-11-22, against PLAN.md draft 2 (after the owner's decisions, before the dispositions in PLAN §12.2). 180,013 tokens. Verbatim below, except that absolute paths into the checkout are shortened to repository-relative ones. PLAN and plan.json line numbers refer to draft 2.

1. **High — Incomplete evidence arguments.** [PLAN.md:284](design/semantic-index/PLAN.md:284) returns `{file_path, symbol, ref_sha, line_range}`, but [`add_evidence` requires `kind`](mcp-server/src/tools/evidence.ts:42). SI7’s “accepted unchanged” gate therefore cannot pass. **Fix:** require the caller to add an explicitly chosen `kind`, and change the guidance and gate accordingly.

2. **High — Refresh ambiguity is unreachable under the identity rules.** [PLAN.md:268](design/semantic-index/PLAN.md:268) makes colliding IDs unique with `#2`, `#3`; [§4.5](design/semantic-index/PLAN.md:371) requires several definitions with the same ID for `ambiguous`. Duplicating SI8’s fixture definition cannot produce that state. Positional suffixes also change meaning when an earlier sibling is inserted or deleted. **Fix:** separate revision-local occurrence IDs from cross-revision matching keys; define conservative ambiguity detection and gate duplicate insertion, deletion and reordering.

3. **High — Parameter types alone do not identify C++ or C# overloads.** [PLAN.md:265](design/semantic-index/PLAN.md:265) omits C++ member cv/ref qualifiers and C# generic arity and parameter-passing modes. Examples include `f() const` versus `f()`, and `M<T>()` versus `M<T,U>()`. Falling back to positional suffixes makes refresh identity unstable. **Fix:** specify language-specific syntactic discriminators, including generic containing-type identity, and gate their stability across reordering. See the [C++ draft](https://www.eel.is/c%2B%2Bdraft//class) and [C# signature specification](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/language-specification/basic-concepts#75-signatures-and-overloading).

4. **Medium — C++ qualification and declaration handling remain underspecified.** [PLAN.md:252](design/semantic-index/PLAN.md:252) includes bodyless member declarations but omits namespace-level prototypes such as `void run();`. [The identity rule](design/semantic-index/PLAN.md:261) also does not explain how `namespace ns { void Foo::bar() {} }` combines lexical namespace scope with its relative qualified declarator. **Fix:** explicitly cover header prototypes, relative and global qualification, and declaration/definition occurrences; add fixtures for each.

5. **Medium — C# partial declarations need a fragment contract.** [PLAN.md:253](design/semantic-index/PLAN.md:253) does not distinguish a partial method’s defining declaration from its implementing declaration, or identify a class result as one file’s partial fragment. Qualification alone does not resolve these distinctions. **Fix:** return file-local fragments with explicit declaration/implementation and partial markers; gate a class and partial method split across two files, including reading and anchoring each occurrence. These are distinct language constructs in the [C# specification](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/language-specification/classes).

6. **High — The package omits the index’s own queries.** [PLAN.md:241](design/semantic-index/PLAN.md:241) puts queries under `src/code-index/queries/`, while [§4.8](design/semantic-index/PLAN.md:420) adds only grammars and notices to the package. [`build` runs only `tsc`](mcp-server/package.json:48), which does not copy `.scm` files. **Fix:** assign query copying or bundling to SI2/SI3, specify installed lookup paths, and assert query presence and loading from the installed tarball.

7. **High — Line containment still permits cross-symbol excerpts.** [PLAN.md:336](design/semantic-index/PLAN.md:336) validates line spans, but [`requireEvidenceCitation`](mcp-server/src/helpers.ts:584) searches entire cited lines. With two functions on one line, evidence anchored to the first can quote the second. This leaves draft 1 finding 4 incompletely fixed. **Fix:** additionally check excerpts against the definition’s exact byte extent, intersected with cited spans; add a same-line neighbouring-definition fixture.

8. **Medium — Documentation edits can produce a false `same-text` hint.** [PLAN.md:269](design/semantic-index/PLAN.md:269) extends citations over leading comments, but hashes the declaration’s bytes. Editing a leading comment without changing line count can leave both hash and coordinates unchanged despite changing cited text. **Fix:** hash the complete citeable span, or retain a separate documentation hash and include it in refresh classification.

9. **Medium — Parse failure can be reported as deletion.** [PLAN.md:369](design/semantic-index/PLAN.md:369) defines `gone` from readable-file absence, while the extractor permits `parse-partial`. A syntax error can hide an existing definition from the query. **Fix:** specify when parser coverage proves absence; otherwise return `unavailable` or an explicit uncertain state. Gate a malformed target definition alongside an intact neighbouring definition. Draft 1 finding 7 remains incomplete.

10. **High — Cache recovery still lacks safe ownership.** [PLAN.md:207](design/semantic-index/PLAN.md:207) replaces a database that “cannot be opened,” without distinguishing contention or permissions from corruption or coordinating active WAL users. [Generation collection](design/semantic-index/PLAN.md:196) likewise names no mechanism protecting a long-running process. **Fix:** specify shared lifetime ownership and exclusive recovery/collection, handle the database and WAL together, and return unavailable for ordinary open failures. Gate recovery and collection while another process holds the generation open. Draft 1 finding 6 remains incomplete.

11. **Medium — Existing record readers do not enforce every promised search exclusion.** [PLAN.md:384](design/semantic-index/PLAN.md:384) promises no unreachable records by delegating to existing readers. However, [`readNarratives`](mcp-server/src/invariants.ts:584) performs no revision check, and [`get_claims`](mcp-server/src/tools/claims.ts:793) checks revision applicability only when given `query_sha`. **Fix:** specify the extra reachability policy and arguments per record kind; gate unreachable narratives and claims, plus phase-ineligible explanations. Replacement/withdrawal fixtures alone do not close draft 1 finding 9.

12. **Medium — Symbol-account matching and standing would disagree.** [PLAN.md:347](design/semantic-index/PLAN.md:347) assigns alias matching to `locus.ts`, but [`standing.ts:1049`](mcp-server/src/standing.ts:1049) separately requires exact symbol equality. A bare-name account could contain anchored evidence while reporting `not-individually-cited`. **Fix:** explicitly include `standing.ts` in SI7 and share ambiguity-aware matching across both surfaces; gate the complete `describe_locus` result, including standing.

13. **High — Refusal documentation is scheduled after its required regression checks.** SI5–SI7 add refusal-parity rows and run its regression, but skill documentation arrives in SI9 ([plan.json:312](design/semantic-index/plan.json:312), [PLAN.md:596](design/semantic-index/PLAN.md:596)). The [checker requires an existing reference carrying the refusal phrase](mcp-server/scripts/check-refusal-parity.mjs:515). **Fix:** deliver each refusal’s minimal documentation in its implementation packet; reserve SI9 for broader workflow guidance.

14. **High — SI7 retains a private, old-store migration dependency.** [plan.json:430](design/semantic-index/plan.json:430) runs `test-existing-store-migration.mjs`. That script [requires a populated private store and exits 2 without it](mcp-server/test-existing-store-migration.mjs:21). It contradicts D6 and prevents a clean public checkout from completing SI7. SI4 also retains new work on `storageManifest`, whose [call sites belong to legacy migration](mcp-server/src/project.ts:355). **Fix:** remove these old-store requirements; gate new schema, transactions and append-only contracts using fresh committed fixtures.

15. **Medium — SI10 registers a gate that does not exist yet.** [SI10](design/semantic-index/plan.json:561) depends only on SI9 but must register every gate, including SI11’s later-created report test. Its static gate can pass while the resulting CI fails on the missing script. **Fix:** execute SI11 before SI10 and add the dependency, or register gates incrementally and reconcile them after SI11.

16. **Medium — The hybrid guidance gate reaches beyond index guidance.** [PLAN.md:465](design/semantic-index/PLAN.md:465) prohibits every sentence limiting file reading. Existing instructions include [“No method bodies yet” during scoping](.claude/skills/amanuensis/references/phase-1-scope.md:3) and [store-only memory auditing](.claude/skills/amanuensis/references/memory-audit.md:8). A literal gate requires unrelated workflow changes. **Fix:** scope the assertion to index-related navigation guidance: it must introduce no restriction on whole-file reading.

17. **Medium — The prescribed call-log copy can lose the baseline.** [PLAN.md:496](design/semantic-index/PLAN.md:496) says to retain `calls.db`, but the logger [uses WAL mode](mcp-server/src/call-log.ts:291) and [queues writes asynchronously](mcp-server/src/call-log.ts:224). Copying only the main file while the server runs can omit recent calls. **Fix:** prescribe a consistent SQLite snapshot after flushing, or a clean shutdown before copying; document that log-only input supplies logged envelope bytes and outcomes, while token totals require transcripts.

18. **Low — Draft 1’s evidence-measurement correction was declared moot without removing its claims.** [PLAN.md:672](design/semantic-index/PLAN.md:672) says the census was removed, but [§2.2](design/semantic-index/PLAN.md:125) and the summary retain its results. The [prototype checker](design/semantic-index/baseline/evcheck.mjs:28) decodes entities and drops short fragments, unlike the real ingress checker. **Fix:** remove those headline claims or label all retained counts as historical heuristic results that do not measure current citation validity; add no replacement census work.

The lane is not ready to launch. SI7 and SI8 contain contradictory acceptance conditions, refusal-parity dependencies are ordered incorrectly, and installed query assets are unassigned. Identity, citation containment and cache recovery need explicit contracts before implementation. The named existing regression scripts are present, but the migration regression is unsuitable for this release. No modifications, builds, installations or tests were performed.
